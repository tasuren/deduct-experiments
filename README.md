# 推論トレースシステム（deduct_poc）

物事の筋道、演繹が正しいかどうかを確かめる仕組みを模索するための、実験的プログラム。旧名、演繹チェッカー。

文書:

- `CONCEPTS.md`: 概要
- `OVERVIEW.md`: プログラム内容
- `ARCHITECTURE.md`: 設計概要
- `model/trace_inference_system_ja.tex`: 簡易的な数学モデルを記述したペーパー

`model/basic.pl`にPrologによる実装があります。

## きっかけ

このリポジトリにあるコードを作るきっかけとなったのは、以下の二点が強いです。

- 前提の共有がされないことによる、文章の理解の困難さを感じていた（教科書など）
- ものの存在は状態遷移によって定義されるのではないか、という考え

この考えの元、文章上の前提の欠落を検出するプログラムが欲しいと思い、その意味論の考察を行いました。
その成果物として、実際に動く形にしたプログラムがこのdeduct_pocです。

今もこれについて考え続けていますが、
誰かのポジティブな意味での刺激になることを期待して、
一旦ここに記録します。
